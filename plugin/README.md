# clinic-plugin-pack

Clinic front-desk skills for Claude Code — the medical plugin pack compiled
from [packc](https://github.com/habib-analyst/packc)'s clinic pack.

Your Claude Code, clinic-ready: a patient or front-desk staffer can find a
doctor, book, reschedule, and cancel appointments in natural language, with
typed contracts on every tool call and a safety policy compiled in — booking
and cancellation require confirmation by default, and emergencies escalate
to a human.

## Skills

| Skill | What it does | MCP tool |
|---|---|---|
| `find-doctor` | Find doctors by specialty and day | `doctors_search` |
| `book-appointment` | Book an appointment with a named doctor | `appointment_book` |
| `reschedule-appointment` | Move an appointment to a new day and time | `appointment_reschedule` |
| `cancel-appointment` | Cancel an appointment | `appointment_cancel` |

## How it is built

This plugin is **compiled, not hand-written**. The source of truth is
`src/clinic.pack` — a typed packc declaration (10 schemas, 4 skills, the
`care` flow, and the escalation policy). The
[packc](https://github.com/habib-analyst/packc) compiler produced:

- `skills/<skill>/SKILL.md` — one official-format skill file per declared
  skill, generated from the typed source (triggers, schemas, steps,
  escalation text all come from the `.pack` file).
- `mcp/clinic_mcp_server.py` — a zero-dependency MCP server (JSON-RPC over
  stdio: `initialize`, `tools/list`, `tools/call`) generated by packc. It
  validates every call against the pack's typed input schemas and rejects
  type errors before dispatch.
- `src/clinic.SKILL.md` — packc's own pack-level SKILL.md emission, kept as
  the compiled reference document.

Recompile from the plugin root's parent project with
`python3 tools/build_plugin.py` (see the project repository).

## Install (once listed in the directory)

```
/plugin install clinic-plugin-pack@claude-plugins-official
```

Until then, the folder can be used as a local plugin/marketplace source in
Claude Code. The MCP server needs only Python 3.10+ — no third-party
packages.

## Safety model

- Booking and cancellation are **confirm-tier** by default; sending
  messages is auto (declared in the pack's `escalate` block).
- `is_emergency == true` escalates to **human_only**.
- Scope is front-desk logistics only. This pack does not diagnose, triage,
  or give medical advice, and it ships with sample contract handlers —
  connect it to a real roster/scheduling backend before clinical use.
